# 全壘打大賽 HOME RUN — 多人同時下注網頁遊戲（模擬版）

**線上試玩：https://acc2023156.github.io/HomeRun/**

> 使用**模擬遊戲幣**，不涉及真實金錢，僅供遊戲開發與演示。玩法由 [Crash](https://github.com/acc2023156/Crash) 改編。

## 玩法

1. 下注階段 7 秒，打者擊球後球開始飛行，**倍數 = 飛行距離 ÷ 10**（35 m = 3.50×）。
2. 球被接殺或落地前按「兌現」拿走目前倍數；沒兌現就出局。
3. **飛過全壘打牆 = 牆距倍數 × 2**，本局結束，所有還沒兌現的人一起拿 2 倍。

| 方向（外野切三等分） | 牆距 | 全壘打倍數 |
|---|---|---|
| 左外野（-45° ~ -15°） | 110 m | 11.0 × 2 = **22.0×** |
| 中外野（-15° ~ 15°） | 122 m | 12.2 × 2 = **24.4×** |
| 右外野（15° ~ 45°） | 114 m | 11.4 × 2 = **22.8×** |

- 擊球方向在擊球瞬間公開，球場與牆面都標示牆距。
- 自動兌現設 `99`（或按「HR」）= 只收全壘打。

## 雙視角

| 視角 | 何時 | 內容 |
|---|---|---|
| 本壘後方（打擊視角） | 投球倒數，到打者開始揮棒（擊球前 0.18 秒）；點擊畫面＝下注，不顯示距離 | 鏡頭跟著球平移、轉向、仰角；巨蛋、看台、記分板、連續的綠色全壘打牆（牆面標示牆距） |
| 俯視全場 | 揮棒開始起（轉場 0.25 秒，伴隨鏡頭掃動聲與遊戲風擊球聲）；點擊畫面＝兌現 | 扇形球場（外野牆為通過三個牆距點的單一圓弧）、三段牆距與全壘打倍數、本局方向高亮、球影子與軌跡 |

場上只有投手與打者（二頭身、大眼）：下注最後 1.5 秒投手抬腿投球，擊球瞬間打者（紅色頭盔）揮棒，打完留在原地。不判定接殺或出局，只看飛行距離或全壘打；球落地時還沒兌現就輸。觀眾是固定在看台上的 3D 座位點，鏡頭移動時留在原地。切換條件只看目前距離，所有球的彈道高度相同，畫面不會提前透露落點。全壘打時有 HOME RUN 大字、煙火、歡呼音效。

## RTP 98.5% 的數學

同一顆種子：`h = SHA256(seed:homerun:局號)`

- 前 52 bits → `u ∈ (0,1]`，決定距離；接下來 32 bits → 擊球方向。
- 存活函數（球飛到 x 倍還沒落地的機率），`R = 0.985`，`x0 = 6`（60 m）：

```
S(x) = R / x                                x ≤ 6       （與原本 Crash 相同）
S(x) = R / x · (1 − 0.5·((x−6)/(H−6))²)     6 < x < H   （彈道下墜）
全壘打機率 = S(H) = R / (2H)                 → 押全壘打期望值 = 2H · R/(2H) = R
```

- 由 `u` 反推：`u > R/6` → 距離 = R/u（同 Crash）；`u ≤ R/(2H)` → 全壘打；其餘二分搜尋 `S(x) = u` → 外野接殺點。
- **任何兌現策略的期望值都 ≤ 98.5%**。模擬 30 萬局：

| 策略 | RTP |
|---|---|
| 1.5× ～ 6× 兌現 | ≈ 98.2% ～ 98.5% |
| 8× 兌現 | ≈ 91% |
| 10× 兌現 | ≈ 72% |
| 只收全壘打 | ≈ 98.5%（全壘打率：左 4.48%、中 4.04%、右 4.32%） |

## 其他

- 100 個暫代帳號，每局隨機 5~60 人下注（保守／穩健／冒險／全壘打型策略）。
- 手動／自動投注、公平性驗證（可重新計算距離、方向、是否全壘打）、手機自適應。
- `?return=<大廳網址>` 會顯示「‹ 大廳」按鈕（只接受自家網域）。
